The hybrid split

With Nano, the message stays on the laptop. The cloud gets the empty form.

Three Firebase AI Logic model instances: fill on the device, teach from the empty form, and a consent path that waits for your Yes.

On your laptop

Gemini Nano · InferenceMode.ONLY_ON_DEVICE

  1. The live form becomes a JSON schemaRead from the page: labels, names, options, formats.
  2. Nano answers inside that schemaPassed as responseConstraint: valid JSON in 135/135 held-out fills.
  3. Code checks every value against your textIn the message, fits the box, one candidate. Gate v4.
  4. Boxes press through or stay amberEvery fill shows its inferenceSource.
Customer text stays left

In the cloud

gemini-3.5-flash-lite · InferenceMode.ONLY_IN_CLOUD

  1. The empty form, never the messageYou can read the payload before it is sent.
  2. A teacher writes hints for cryptic boxesCNEE became “Enter the name of the consignee”, returned through responseSchema.
  3. Saved by form fingerprintFirestore keys hints by structure, never content.
  4. Guarded and tunableApp Check in front of AI Logic; Remote Config holds the 2,000-character cap, timeout and kill switch.

No Nano? A consent sheet comes before that one message goes to the cloud (PREFER_ON_DEVICE). Recorded check: 0 AI requests before Yes; the sheet counted 682 bytes (2 × 341: one attempt timed out and was retried) and Chrome's wire log saw the same 2.

Questions a judge would ask

Is the message really never sent?

With Gemini Nano, fills run ONLY_ON_DEVICE. The hosted check saw 0 requests during 4 fills and 0 message words in any request; a planted canary was caught. The receipt page shows the log. It covers this page's requests, not the whole browser.

No Nano? Here is what you still get.

A plain notice, a recorded run labelled as recorded, and a consent sheet showing the bytes before one message goes to the cloud. Nothing is sent before Yes; the fill is labelled in_cloud. The gate above works without Nano too.

Then what does the cloud do?

Two jobs. It reads the empty form and writes hints for cryptic boxes (measured: +0.1 points on the hard form, small). Without Nano it runs that one message after Yes; the sheet's byte count matched Chrome's wire log.

Why do some boxes stay amber?

Code could not accept them: not in your text, wrong format, two phone numbers, an assumed year, or a recipient name. Amber costs a second; a wrong blue box costs an error.

Does it work on any website?

No. It is a hosted web app with three forms; there is no extension, so it does not fill other sites.

What is synthetic?

Every message: invented people, phone numbers in the 5550 block. Nothing on the fill path is mocked.
